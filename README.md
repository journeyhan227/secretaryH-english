# secretaryH English Daily

Public static hosting for the latest NYT The Morning study material and Scriptable widget metadata.

- `index.html`: fallback landing page
- `latest.html`: publish only after a verified lesson is available
- `today.json`: status is `pending` until publication

The existing 08:00 ChatGPT automation must be explicitly updated and its GitHub write workflow verified before claiming automatic publication. Do not publish full copyrighted newsletter text or private Gmail links.
